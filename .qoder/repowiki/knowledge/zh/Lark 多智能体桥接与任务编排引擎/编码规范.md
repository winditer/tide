- 所有 Agent 交互指令均通过 `/` 前缀识别（如 `/codex`, `/plan`, `/cd`），并在 `on_text` 函数中通过正则匹配进行路由分发。
- 任务执行结果与状态更新通过 Lark 交互式卡片（Interactive Cards）呈现，卡片动作通过 `action.value` 中的 JSON 负载触发后端 `handle_card_action` 逻辑。
- 采用“批准-重试”机制处理权限敏感操作，当 Agent 返回待审批信号时，创建 `PendingApproval` 记录并暂停进程，待用户在 Lark 卡片点击批准后，使用提升的权限模式（如 `bypass_permissions`）重新启动任务。
